## 🛠️ How to Install AutoTalent on Arch

1. **Use the AUR**
   AutoTalent is available on the Arch User Repository (AUR). ([AUR][1])

   * Clone the AUR package:

     ```bash
     git clone https://aur.archlinux.org/autotalent.git
     cd autotalent
     ```
   * Build and install:

     ```bash
     makepkg -si
     ```
   * This builds the LADSPA plugin and installs it. The AUR package depends on `ladspa`, so make sure you have that installed. ([AUR][1])

2. **Verify / Use**

   * After installation, you should have a `.so` plugin (e.g. `autotalent.so`) in your LADSPA plugin directory (commonly `/usr/lib/ladspa` or similar).
   * Use it in a DAW or audio host that supports LADSPA plugins.

---

## ⚠️ Things to Be Careful Of

* The AUR package pulls the source from the official AutoTalent site: `http://tombaran.info/autotalent.html` ([AUR][2])
* Because it's an old plugin, it might not build cleanly depending on your system, but many people have used the AUR version successfully.
* Always review the PKGBUILD before building AUR packages, especially for audio plugins.
* Make sure you have the `base-devel` group installed (for `makepkg`) and enough tools (GCC, make, etc).
